# موقع المنهج

مبني باستخدام MkDocs Material.

## التشغيل محليًا
```
pip install -r requirements.txt
mkdocs serve
```
ثم افتح: http://127.0.0.1:8000

## إضافة موضوع جديد
1. أضف ملف .md جديد داخل مجلد docs/ (داخل مجلد الفصل المناسب)
2. أضف سطر له في قائمة nav داخل mkdocs.yml
3. اعمل commit و push — الموقع هيتحدث تلقائيًا
